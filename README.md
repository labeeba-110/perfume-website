# 🌸 Perfume Website

A static perfume website developed using **HTML5** and **CSS3** as a **Semester 1 ICT project**.

## 📖 Project Overview

This project is a multi-page perfume website created to practice the fundamentals of web development. It features a clean and elegant design with multiple pages for navigation, products, and user authentication.

---

## ✨ Features

- 🏠 Home Page
- ℹ️ About Page
- 🛍️ Products Page
- 📞 Contact Page
- 🔐 Login Page
- 📝 Signup Page
- 🎨 Modern responsive layout
- 🌸 Elegant perfume-inspired design

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## ▶️ How to Run

1. Download or clone this repository.
2. Open `index.html` in your preferred web browser.

No installation or server is required.
